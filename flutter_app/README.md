# VRRITTAM Flutter App

This is a Flutter implementation inspired by the existing education portal design.

## Run locally

1. Install Flutter from https://flutter.dev/docs/get-started/install
2. Open a terminal inside this folder
3. Run:

```bash
flutter pub get
flutter run
```

## Notes

- The project is intentionally lightweight and built as a clean landing page and dashboard-style UI.
- The design matches the VRRITTAM brand colors and education portal feel.
